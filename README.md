# ✈️ Telegram Mini Playbook — твоя телега как руки твоего ИИ

МИНИ-плейбук: как развернуть **свой** MCP-коннектор к личному **Telegram** на своём
сервере — чтобы любой твой AI-клиент (Claude Code на ноуте, Claude-приложение на
телефоне, агент в Cursor) умел читать твои чаты, искать по ним и слать сообщения.
Это выжимка «только Telegram» из большого плейбука
[`mcp-messengers-playbook`](https://github.com/rocketmandrey/mcp-messengers-playbook)
(Telegram + WhatsApp) — здесь один путь, короче и без развилок. Зеркало
[`whatsapp-mini-playbook`](https://github.com/rocketmandrey/whatsapp-mini-playbook), только про телегу.

> **👉 Не знаешь, с чего начать — открой [`START_HERE.md`](START_HERE.md).** Там
> копипаст-промпт агенту: вставил — и он ведёт тебя по шагам. Кода знать не нужно.

## Обещание

Ты пишешь обычными словами — «догони меня по чату с Н. за 3 дня», «найди, что клиент
писал про сроки», «набросай ответ — отправлю сам» — и агент сам лезет в твой Telegram и
действует. Один контейнер на твоём VPS — и руки появляются сразу у всех клиентов: ноут,
второй комп, телефон. Телега легче вацапа: **нет Chromium, хватает 256 МБ RAM** — можно
взять самый дешёвый сервер.

## Кейсы — не теория, всё из жизни автора

1. **🧵 Догнать чат обычными словами.** «Что решили в рабочем чате за 3 дня?» → агент
   читает и отдаёт короткое саммари с цитатами и датами. Работает по личке, группам,
   Избранному — по всему сразу.
2. **✍️ Ответ одним промптом.** Присылают сообщение → «прочитай и набросай ответ» →
   агент сверяет с целью и пишет черновик. Ты жмакаешь «отправить». Фокуса — ноль.
3. **🔍 Поиск по годам переписки.** «Что я обещал клиенту в марте?» → находит и цитирует
   исходное сообщение по глобальному поиску.
4. **🧠 Сырьё для контента.** Твои же голосовые и посты в Избранном — материал: агент
   собирает из них черновик поста или гайд (см. также
   [`telegram-second-brain-playbook`](https://github.com/rocketmandrey/telegram-second-brain-playbook)).
5. **📱 Всё это — с любого устройства.** Коннектор вешается один раз на аккаунт
   claude.ai и работает на телефоне, в вебе и в десктоп-приложении, без ноута.

## Мини-словарь (для тех, кто не кодит)

- **MCP** (Model Context Protocol) — стандарт, которым AI-клиент получает доп-инструменты.
  MCP-сервер = «коробка с инструментами»: подключил — и агент умеет читать/искать/слать.
- **сессия** (`sessions/<token>.session`) — файл-пропуск в аккаунт без логина = пароль.
  Создаёшь сам (логин по номеру на `/setup`), не шаришь, в репо её нет.
- **Telethon** — библиотека, которая говорит с Telegram по официальному протоколу MTProto
  как обычный клиент (userbot). Никаких «связанных устройств» и QR-мостов, как у вацапа.
- **Bearer-токен / секрет-в-URL** — ключ доступа к MCP. Утёк — равно утекла сессия;
  ротируется одной строкой (в nginx / `.env`).
- **nginx** — «швейцар»: единственная дверь с улицы к серверу, с https-замочком.
- **certbot** — бесплатный https-сертификат, сам себя продлевает.
- **Docker** — «коробка», в которой крутится готовый софт; ставить руками ничего не надо.
- **смок-тест** — короткая проверка «дым не идёт» перед тем, как сказать «готово».

## Что нужно заранее (prereqs)

- **VPS** — Ubuntu/Debian, root, **1 ГБ RAM достаточно** (контейнер ест ~256 МБ — тут
  нет Chromium, в отличие от вацапа), публичный IPv4; от ~300 ₽/мес.
  **Нет сервера — не стоп:** агент купит его с тобой за 10 минут по
  [`02_TELEGRAM_MCP.md §0`](02_TELEGRAM_MCP.md).
  Telegram **работает и с российских IP** (в отличие от WhatsApp) — локацию можно любую.
- **Имя для https** (доступ с телефона) — покупать домен не обязательно: бесплатное
  `<IP>.sslip.io` работает из коробки; свой домен ~200–400 ₽/год — запасной надёжный путь.
- **`API_ID` / `API_HASH`** — бесплатно на [my.telegram.org](https://my.telegram.org) →
  API development tools (2 минуты). Больше внешних ключей базовый путь не требует.
- **Твой телефон** — принять код входа при логине на `/setup`.

Итого бюджет: VPS ~300–600 ₽/мес (домен опционален — бесплатный `sslip.io` покрывает
https). API-ключей и подписок базовый путь не требует.

## ⚠️ Прочитай ПЕРВЫМ (30 секунд, иначе потеряешь аккаунт или сольёшь переписку)

1. **MCP = полный доступ к аккаунту.** Сервер с твоей сессией читает и шлёт всё, что
   можешь ты. Поднимай на СВОЁМ сервере.
2. **Сессия и Bearer-токен = пароль.** `.session`-файл и токен дают доступ к аккаунту
   без логина. `chmod 600`, никогда в git, утёк → ротируй.
3. **Порт MCP — только `127.0.0.1`.** Наружу один nginx с SSL. Страницу `/setup` закрой
   от чужих (allow/deny по IP) — иначе на твоём сервере залогинится кто угодно.
4. **Отправку — только с подтверждением.** Чужие сообщения — недоверенный ввод
   (prompt-injection). По умолчанию — черновик.

Полные гардрейлы — [`01_SECURITY.md`](01_SECURITY.md), читать обязательно.

## ✅ Что этот плейбук покрывает

- Свой Telegram MCP (`fast-mcp-telegram`, Telethon) на VPS: чтение, глобальный поиск,
  отправка/редактирование, инфо о чатах, сырой MTProto.
- Подключение Claude Code (`--scope user`) и claude.ai-коннектора — один раз на аккаунт,
  работает на телефоне, в вебе и в десктоп-приложении.
- Безопасность коннектора: сессия, 2FA, секреты, ротация, порты, анти-бан.
