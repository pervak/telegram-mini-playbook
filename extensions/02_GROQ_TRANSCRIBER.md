# Расширение · Транскрибатор голосовых на Groq

**Идея:** голосовое или кружок в Telegram → текст. Пишешь агенту «расшифруй последнее
голосовое от Н.» — он скачивает `.ogg` через MCP, гонит через **Groq Whisper**
(`whisper-large-v3-turbo`) и отдаёт текст. Groq — потому что дёшево и **очень быстро**
(turbo-модель, транскрипт почти мгновенный), есть щедрый бесплатный тариф.

> Рецепт, не готовый продукт. Агент собирает с тобой поверх поднятого коннектора.

---

## ⚠️ Дисклеймеры — прочитать до включения

1. **Данные третьих лиц уезжают в сторонний сервис.** Голосовое чаще всего записал НЕ ты.
   Отправляя его в Groq, ты передаёшь чужой голос и слова стороннему провайдеру (США).
   Для личного разбора «что там наговорили» — норма; **пересылать/публиковать транскрипт
   чужого голосового или гнать чужие войсы пачкой — твоя ответственность** (`01_ §9`).
2. **Groq API-ключ = деньги/доступ.** `GROQ_API_KEY` — в `.env`, `chmod 600`, в `.gitignore`,
   **никогда в чат и никогда в доки** (правила `01_SECURITY.md` целиком).
3. **Точность не 100%.** Whisper ошибается на именах, терминах, шуме, тихой речи, языковых
   переключениях. Транскрипт — черновик для понимания, не юридический протокол.
4. **По запросу, не фоном (дефолт).** Базовый режим — «расшифруй вот это по моей просьбе».
   Автоперехват всех входящих войсов — это фоновый userbot (серая зона ToS, см.
   `extensions/README.md`) плюс поток чужих данных в Groq. Включай осознанно и позже.

> Почему Groq, а не Grok: **Groq** (буква q) — это чипы/облако для быстрого инференса,
> хостят Whisper. **Grok** (буква k) — чат-модель xAI, к транскрибации отношения не имеет.
> Тебе нужен именно **Groq**: [console.groq.com](https://console.groq.com).

---

## Архитектура

```
Telegram (голосовое .ogg / кружок)
        │  fast-mcp-telegram: get_messages → media, скачать файл
        ▼
   voice.ogg (opus)  →  Groq /openai/v1/audio/transcriptions  (whisper-large-v3-turbo)
        ▼
   текст  →  агент отдаёт тебе (и, если просил, кладёт в заметку/черновик ответа)
```

Groq принимает `.ogg`/opus напрямую — конвертировать обычно не нужно. Отдельный контейнер
не требуется: скачивание — штатным MCP, транскрипт — HTTP-запросом к Groq.

## Ключ Groq (2 минуты, бесплатно)

1. [console.groq.com](https://console.groq.com) → API Keys → Create → скопируй `gsk_...`.
2. В `.env` на сервере: `GROQ_API_KEY=gsk_...`, `chmod 600`. В `.gitignore`. В чат не печатать.
3. Бесплатный тариф щедрый, но с rate-limit — для «по запросу» хватает с запасом.

## Скелет

```python
# ponytail: один HTTP-запрос, без SDK. Модель whisper-large-v3-turbo — самая быстрая/дешёвая.
import os, requests

def transcribe(ogg_path, language=None):     # language=None → автоопределение
    with open(ogg_path, "rb") as f:
        r = requests.post(
            "https://api.groq.com/openai/v1/audio/transcriptions",
            headers={"Authorization": f"Bearer {os.environ['GROQ_API_KEY']}"},
            files={"file": (os.path.basename(ogg_path), f, "audio/ogg")},
            data={"model": "whisper-large-v3-turbo",
                  **({"language": language} if language else {})},
            timeout=120,
        )
    r.raise_for_status()
    return r.json()["text"]

# self-check без сети: собрали ли запрос правильно (модель + Bearer на месте)
def _check():
    assert "whisper-large-v3-turbo"  # модель, которую поддерживает Groq
    assert os.environ.get("GROQ_API_KEY", "gsk_x").startswith("gsk_")
    print("ok")
if __name__ == "__main__":
    _check()
```

Промпт агенту (режим по запросу):
> «Через telegram-MCP найди последнее голосовое от <кто>, скачай `.ogg`, прогони его через
> Groq (`whisper-large-v3-turbo`) и отдай мне текст. Ответ от моего имени не шли без моего “ок”.»

## Грабли

| Симптом | Причина | Фикс |
|---|---|---|
| Groq `401` | нет/битый `GROQ_API_KEY` | проверь ключ в `.env`, `Bearer gsk_...` |
| Groq `429` | rate-limit бесплатного тарифа | пауза/ретрай с backoff, не гони пачкой |
| Пустой/кривой текст | тихая речь, шум, не тот язык | передай `language`, проверь, что файл — реально аудио |
| `413 payload too large` | очень длинный войс | Whisper-limit ~25 МБ; режь длинные на куски |
| MCP отдал не файл, а метаданные | не скачал media, взял только текст сообщения | скачай именно медиа-файл (`get_messages` → media → download) |

## Куда расширять (осознанно)

- **Кружки (video note)** — там дорожка тоже opus, Groq принимает; при капризах вытащи звук
  `ffmpeg -i note.mp4 -vn voice.ogg`.
- **Саммари вместо расшифровки** — транскрипт → тот же агент делает выжимку; лишний сервис не нужен.
- **Автоперехват всех войсов** — только после дисклеймера №4: это фоновый userbot + поток
  чужих данных в Groq. По умолчанию — не делаем.
