# 🚀 START HERE — как дать своему ИИ руки в Telegram

Тебе **не нужно ничего знать про код**. Нужно дать своему AI-агенту (Claude Code или
Cursor) правильную команду — дальше он ведёт по шагам. Ты только подтверждаешь и
принимаешь код входа в телефоне.

> Что вообще делаем: поднимаем на твоём сервере готовый **MCP-сервер** к твоему Telegram
> (он ходит в аккаунт по официальному протоколу как обычный клиент). После этого любой
> твой Claude (на ноуте, на телефоне) умеет читать твои чаты, искать по ним и слать
> сообщения — обычными словами, без кода. Софт готовый, писать ничего не надо.

---

## Шаг 0 — скачай репозиторий себе

На странице репо в GitHub: зелёная кнопка **Code → Download ZIP** → распакуй.
(Если знаешь git: `git clone <url этого репо>`.)

**Никогда не открывал терминал (Mac):** нажми ⌘+пробел, набери «Терминал», Enter.
В окне набери `cd ` (с пробелом), перетащи мышкой распакованную папку прямо в окно
терминала, нажми Enter — ты «внутри папки».

**Claude Code ещё не установлен:** команда установки — на официальной странице
[claude.com/claude-code](https://claude.com/claude-code) (подписка Pro подходит).
Поставил → набери в терминале `claude`, Enter — откроется диалог, туда и вставишь
промпт из Шага 1.

Сервер и домен покупать заранее НЕ нужно — агент проведёт по покупке сам
([`02_TELEGRAM_MCP.md §0`](02_TELEGRAM_MCP.md)).

## Шаг 1 — скопируй промпт агенту

Открой Claude Code / Cursor в папке этого репозитория и вставь:

```
Ты — мой оркестратор по подключению личного Telegram к нейронке через MCP.
Прочитай этот репозиторий, особенно: AGENTS.md, 01_SECURITY.md,
02_TELEGRAM_MCP.md и деплой-комплект examples/tg-mcp/.

Дальше веди меня ШАГ ЗА ШАГОМ (по одному шагу, спрашивай перед каждым):
1) выясни вводные: какие клиенты подключаем (Claude Code на ноуте / телефон /
   оба); сервер у меня есть или поднимаем; на какой аккаунт вешаем (предупреди,
   что лучше отдельный/второстепенный, см. 01_SECURITY.md §1); стоит ли у меня
   на аккаунте облачный пароль (2FA) — если да, логин будет ТОЛЬКО по номеру;
2) ПРОВЕРЬ ПРЕРЕКВИЗИТЫ: VPS (root, 1 ГБ RAM хватает — тут нет Chromium),
   поддомен tg-mcp.* и A-запись на IP (нужна для https и доступа с телефона);
   если сервера или домена НЕТ — сначала пройди со мной 02_TELEGRAM_MCP.md §0
   (покупка VPS и sslip.io/домен под ключ);
3) ключи: заведи со мной API_ID/API_HASH на my.telegram.org (я залогинюсь сам),
   впиши их в .env на сервере, chmod 600; секрет для мобилы сгенери САМ
   (openssl rand -hex 16); НЕ печатай .env и секреты в чат;
4) проверь безопасность по 01_SECURITY.md: .env в .gitignore, порт MCP только
   на 127.0.0.1, /setup закрыт allow/deny по моему IP;
5) подними контейнер по 02_TELEGRAM_MCP.md из examples/tg-mcp/ (docker compose
   up -d --build → chown -R 1000:1000 sessions/), потом nginx + certbot;
6) дай мне ссылку /setup, я войду ПО НОМЕРУ и приму код в телефоне; убедись,
   что у ЭТОГО MCP своя отдельная сессия (не переиспользуй чужую — AuthKeyDuplicated);
7) подключи клиентов: Claude Code (claude mcp add --scope user --transport http,
   заголовок Authorization: Bearer <TOKEN>) и claude.ai-коннектор для телефона
   через секретную nginx-локацию /m-<SECRET>/mcp (nginx сам подставит Bearer —
   кастомные коннекторы claude.ai свои заголовки не умеют);
   URL коннектора содержит секрет — в чат его НЕ печатай: запиши в файл
   connector-url.txt у меня на рабочем столе, скажи скопировать оттуда в поле URL
   формы, после добавления предложи удалить файл; прогони смок-тест из 02_ §5 —
   без него «не готово» (эндпойнт /v1/mcp, не /mcp!);
8) когда заработало — покажи, как ротировать секрет при утечке.
В конце дай сводку: что поднято, какие секреты я должен хранить и как их менять.

Не делай несколько шагов молча. Я не программист — объясняй простыми словами.
Веди меня как поддерживающий напарник: перед шагом — что делаем и зачем,
после шага — что получилось и сколько осталось. Если что-то упало — спокойно:
«это норма, чиним вот так». Сообщения от моего имени не отправляй без явного
подтверждения.
```

## ✅ Что агент сделает за тебя

- проверит prereqs (сервер, RAM, домен, A-запись) и предупредит, чего не хватает;
- заведёт с тобой `API_ID/API_HASH`, развернёт контейнер `fast-mcp-telegram` из готового
  `examples/tg-mcp/`;
- настроит nginx + SSL (certbot), спрячет порт на `127.0.0.1`, закроет `/setup` от чужих;
- подключит Claude Code (`--scope user` — доступно из любой папки) и телефон;
- прогонит смок-тест: «найди чат X» → реальные чаты; без токена `tools/call` → отказ;
- покажет ротацию секрета при утечке.

## 🙅 Чего агент НЕ сделает (тут нужен ты)

- не примет за тебя код входа — это делаешь ты в своём Telegram;
- не повесит коннектор на твой основной аккаунт без предупреждения о риске;
- не закоммитит секреты и `sessions/` — это запрещено правилами `AGENTS.md`;
- не отправит сообщение от твоего имени без явного подтверждения (по умолчанию — черновик);
- не включит рассылки/массовые действия (прямой путь к бану).
